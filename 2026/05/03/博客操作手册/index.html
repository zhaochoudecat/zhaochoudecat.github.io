4. 常用命令速查表

命令 简写 作用
hexo new "..." hexo n 新建文章
hexo generate hexo g 生成静态页面
hexo server hexo s 启动本地预览服务器
hexo deploy hexo d 发布到远程仓库
hexo clean 无 清除缓存（解决样式不更新等问题）

5. 常见问题

  • 发布后没变化？ GitHub Pages 有缓存，通常需要等待 1-3 分钟。
  • 文章里的图片怎么弄？ 建议使用图床（如 GitHub 图床、SM.MS），或者安装 hexo-asset-image 插件来管理本地图片。
